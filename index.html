Find matches

Turn on, then hover over an object.

Shape & color compares the patch inside the dashed box against every spot in the frame, so copies of the same object light up and everything else dims. Set the box to about the size of the object. Color only lights up every area with the same color. Lock the target to keep tracking it while the video plays.

Snapshot

.kmz files can only be saved from the copy of Frameglass opened from your computer in Edge or Chrome.

From file saves the original frame decoded from the video file at its full resolution, untouched by filters. With edits saves the same full-resolution frame with your adjustments, look and sharpening applied. As shown saves exactly what's on screen, including zoom, the split view, zebras and match highlights. If the video is playing, it pauses first.

Histogram

RGB levels of the processed picture on screen. Bunching at the right edge means clipped highlights.
